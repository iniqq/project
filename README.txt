Auto Lunge (swap) - Fabric mod for Minecraft 26.2

Hold R: swaps to the spear in your hotbar, lunges, swaps back. Every 10 ticks.
Rebind in Controls > Auto Lunge. Change INTERVAL_TICKS in AutoLungeClient.java for speed.

Build with GitHub (no installs):
1. Make a free account at github.com, click + > New repository, name it autolunge, Create.
2. Click "uploading an existing file", drag in EVERYTHING inside this folder
   (including the hidden .github folder - if it won't drag, see steps in chat), Commit.
3. Click the Actions tab, wait for the build to turn green.
4. Open the finished run, download "autolunge-jar" at the bottom, unzip it.
5. Put the jar (not -sources) in %appdata%\.minecraft\mods with Fabric API for 26.2.
